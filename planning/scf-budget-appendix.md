# SCF Budget Appendix

## Revised Ask

**Total requested:** $50,000

This version keeps the full product direction intact while reducing the ask, tightening acceptance criteria, and making the payment structure easier to trust.

## Milestone Table

| Milestone | Deliverables | Acceptance criteria | Amount |
| --- | --- | --- | ---: |
| Milestone 1: Soroban MVP | Inheritance registry contract, policy creation flow, beneficiary and lawyer setup, heartbeat logic on testnet | Public repository, testnet deployment, automated tests, demo of policy creation and simulated inheritance flow | $10,000 |
| Milestone 2: Guardian Oracle + claim pipeline | Oracle notifications, lawyer fallback flow, beneficiary verification, documented security model | Public docs, end-to-end testnet flow, reproducible claim-path demo from inactivity to claim eligibility | $15,000 |
| Milestone 3: SDK + integration + launch readiness | Wallet SDK, contract SDK, demo integrations, deployment package, developer documentation | Public code, installation guides, integration examples, release-ready mainnet package | $25,000 |

## Why this should increase trust

- The ask is reduced from $90,000 to $50,000.
- The payment curve is back-loaded, with half of the compensation tied to the final milestone.
- Every payment is attached to public, reviewable outputs.
- The scope is still consistent with the public roadmap rather than being a completely different project.
